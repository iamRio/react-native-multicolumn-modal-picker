# Security Policy

## Supported Versions

Security updates are provided for the latest release in the 1.2.x line.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

Please upgrade to the latest supported release before reporting an issue when possible.

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do not open a public GitHub issue.

- Email: [marcosdelrio.dev@gmail.com](mailto:marcosdelrio.dev@gmail.com)
- GitHub: [Report a vulnerability privately](https://github.com/iamRio/react-native-multicolumn-modal-picker/security/advisories/new)

Include the affected version, steps to reproduce, and any relevant impact. Please avoid including real users' personal data or publicly sharing details before a fix is available.

We will review the report and let you know whether it is accepted or declined. If accepted, we will work on a fix and coordinate disclosure; timelines depend on the issue's severity and complexity.
